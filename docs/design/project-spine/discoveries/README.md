# Discoveries

This directory stores observations/facts about Planning Lite development.

A Discovery is **not** a Recommendation.

Use a Discovery when the durable statement is primarily:

```text
"we observed X"
```

rather than:

```text
"we should do Y"
```

A Discovery may later support zero, one, or several Recommendations.

Do not create Roadmap work directly from a Discovery without an explicit
Recommendation/Gap/Target decision.
