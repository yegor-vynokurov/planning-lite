# State model

The active pointer is small and records lifecycle stage, stage status, next gate, authorization, and context path. Detailed mutable state stays with the active change. Historical evidence remains in progress and Git. Project documents describe durable facts and domain language. `project/TARGET_STATE.md` and `project/CAPABILITY_MODEL.md` are the explicit durable direction baseline; current implementation status belongs elsewhere and must not be folded into those artifacts. Recommendations describe future opportunities. Decisions preserve rationale. Optional skill-usage logs are observational only.

See `.planning/control/CHANGE_LIFECYCLE.md` for transitions and `.planning/control/STATE_OWNERSHIP.md` for the normative ownership table.
