# Recommendations

Recommendations are durable ideas, risks, or opportunities. Follow `.planning/control/RECOMMENDATION_LIFECYCLE.md`. The item is authoritative; `INDEX.md` is a discovery summary.

Recommendations may start as simple records. Composite recommendations gain stable `REC-NNNN/Ux` semantic units when historical reconciliation or Change coverage requires them. Do not infer parent completion from one completed Change; preserve open/carry-forward/future residue explicitly.
