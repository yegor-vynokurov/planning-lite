# Assess current state

Mode: Audit.

Create an evidence-based assessment using targeted repository inspection. Separate verified facts, risks, gaps, and inference. Update durable project state only where evidence shows it is stale. Capture durable opportunities through `RECOMMENDATION_LIFECYCLE.md`. Do not edit production code.

If the request is to judge whole-project completeness against an intended finished state, require an `ACCEPTED` Target and `CURRENT_BASELINE` Capability Model, then route the formal operation to `CURRENT_CAPABILITY_ASSESSMENT.md`. Do not treat informal assessment gaps as formal Project Spine Gaps; formal Gap identities are derived separately through `CAUSAL_GAP_DERIVATION.md`.
